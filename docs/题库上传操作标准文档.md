# 题镜 StudyLens 题库上传操作标准文档（V1.7）

> 适用范围：StudyLens v1.7.0（versionCode 7）· 面向题库维护者与共享上传用户
> 依据：V1.7 手写清单第 1/3/4/5 条 + 实际源码实现（`UploadScreen.kt`、`GitHubClient.kt`、`StudyRepository.kt`）
> 编制日期：2026-11-24

---

## 1. 目的与术语

本文档规定题目从「录入 → 识别入库 → 校验重复 → 分级上传 → 备份」的标准操作流程，确保共享题库的**结构统一、编号唯一、去重可靠、可追溯**。

| 术语 | 含义 |
|---|---|
| **分级存储** | 题库按 `年级/科目/版本/册别/题型.json` 五级目录存放，每个题型一个 JSON 文件 |
| **Star** | 重要程度权重，取值 0~3；同一题被重复上传时 +1（上限 3） |
| **ID（qidCode）** | 四位十六进制随机数，每题唯一不重复，如 `A3F9` |
| **AI 研判** | 上传图片后由 AI（智谱 `glm-4v-flash`）识别题干/答案/解析并结构化入库 |
| **共享题库** | GitHub 主仓库 `bank/` 目录 + WebDAV（坚果云）备份通道 |

## 2. 上传前准备（必须先完成）

### 2.1 账号与授权
- 必须**已登录**且 AI 授权码已激活（注册后需授权才可调用 AI 功能）。
- 未配置 API Key 时不可上传：内置密文由 `KeyCipher` 解密，管理员可在「我的」页自填覆盖。

### 2.2 设置用户数据（关键，A 模式依赖）
进入「我的」→「用户数据（年级 / 使用教材）」，设置：

| 字段 | 取值示例 | 说明 |
|---|---|---|
| 年级 | 高一 / 高二 / 高三 | 对应 T1，上传 A 模式自动带入 |
| 科目 | 数学 / 物理 / … | 对应 T2 |
| 版本（教材） | 人教A版 / 北师大版 / … | 分级路径第 3 层 |
| 册别 | 上册 / 下册 | 分级路径第 4 层 |

> ⚠ 使用 **A 模式（按用户数据上传）** 前必须设置此项，否则题目维度为「未设置」，会导致归档错位。B 模式不依赖此设置。

### 2.3 文件规格
- 图片：JPG/PNG，拍照或相册选取，**≤ 5MB**，超出会被拒绝并提示压缩。
- 题目文件：JSON 格式（结构见 §5.2），**≤ 5MB**，超出需拆分。
- 建议题干清晰、无遮挡；数学公式用 LaTeX（`公式` 包裹）。

## 3. 标准操作流程

### 步骤 1：进入上传页
底部导航进入「上传题目」页（或对应路由入口）。

### 步骤 2：选择上传模式

| 模式 | 适用场景 | 维度来源 |
|---|---|---|
| **A. 按用户数据上传** | 日常按自己年级/教材录入 | 自动读取「我的」页用户数据，无需手选 |
| **B. 按自定义科目上传** | 代录、跨年级/跨教材整理 | 通过二级菜单逐项选择 |

### 步骤 3：（仅 B 模式）选择二级菜单维度
依次点击单选 Chip 选择：**年级 / 科目 / 版本 / 册别 / 题型**。
- 题型选项：选择 / 填空 / 简答 / 正误判断（对应 MaTp = 1/2/3/4）。
- 默认值：高一 / 数学 / 人教A版 / 上册 / 选择。

### 步骤 4：选择上传方式

- **① 上传图片**：点「📷 拍照」或「🖼 图片」→ AI 识别 → 自动结构化入库。
- **② 上传题目文件**：点「📄 题目文件」→ 选择 JSON → 解析入库（重复题自动跳过，不计 Star）。
- **A 模式**仅提供图片上传入口（拍照/相册）。

### 步骤 5：确认自动共享
页面下方「识别入库后自动共享到题库」开关默认**开启**：
- 开启：入库后立即按分级路径上传共享，重复题自动 Star+1。
- 关闭：仅本地入库，之后可在题库页手动共享（手动共享同样触发校验与 Star+1，并计 +5 积分）。

### 步骤 6：核对结果
操作完成后查看页面反馈：

| 提示 | 含义 | 处理 |
|---|---|---|
| `✅ 已入库 N 题（按用户数据对应）` | A 模式识别成功 | 核对维度是否正确 |
| `✅「…」已共享（编号 XXXX）` | 新增题目，分配了唯一 ID | 记录编号备查 |
| `⚠「…」重复题，Star 权重 +1（现 N）` | 同分级文件内题干重复 | 无需操作；Star 已累加，达 3 封顶 |
| `识别失败 / 共享失败：…` | 网络或密钥问题 | 检查网络与 AI 授权，重试 |
| `❌ 超过 5MB` | 文件过大 | 压缩或拆分后重传 |

> 识别置信度低于 0.6 的题目需人工复核题干、答案、题型后再共享。

## 4. 分级存储规则（核心）

### 4.1 路径生成规则

```
bank/{年级}/{科目}/{版本}/{册别}/{题型}.json
```

示例：`bank/高一/数学/人教A版/上册/选择.json`

| 层级 | 取值来源 | 缺省值 |
|---|---|---|
| 年级 | T1 / 用户数据 / B 模式二级菜单 | 未分年级 |
| 科目 | T2 / 用户数据 / B 模式二级菜单 | 通用 |
| 版本 | edition / 用户教材 | 通用版本 |
| 册别 | volume / 用户教材 | 通用册别 |
| 题型 | MaTp 映射：1选择 2填空 3简答 4正误判断 | 解答 |

> 各级目录名会过滤 `/` 与 `\`，防止路径注入。

### 4.2 去重与 Star 规则

1. 上传某题时，先按该题维度拉取对应的分级 JSON 文件。
2. 在文件内按 **Ma（题干）** 逐条比对：
   - **命中重复**：不新增条目，将已有条目的 `Star` +1（`min(3, old+1)`），回写文件。
   - **未命中**：追加新条目（含 ID/User/Star 全字段），回写文件。
3. 本地同步写回 `shared=true` 与最新 Star 值。
4. 整库拉取时按 **ID 或题干** 双重去重，避免重复入库。

> 注意：图片上传的重复校验发生在「共享」环节（按分级路径比对题干）；JSON 文件导入使用独立的整库合并，重复题直接跳过、**不计 Star**。

## 5. 数据规范

### 5.1 题目字段字典（共享 JSON 条目）

| 键 | 含义 | 取值/示例 |
|---|---|---|
| `T1` | 年级 | `高一` |
| `T2` | 科目 | `数学` |
| `T3` | 是否共享 | `1` / `0` |
| `T4` | 是否能看结果 | `1` / `0` |
| `T5` | 收藏 | `1` / `0` |
| `T6` | 所属知识点 | `["集合","函数"]` |
| `T7` | 难度 | `1`易 / `2`中 / `3`难 |
| `Ma` | 题目内容（题干） | 字符串，公式用 LaTeX |
| `MaTp` | 题型 | `1`选择 / `2`填空 / `3`简答 / `4`正误判断 |
| `o` | 选项（选择题） | `["A...","B..."]` |
| `As` | 答案 | 字符串 |
| `Ana` | 精细解析 | 字符串 |
| `User` | 上传者（溯源） | 登录用户名，未登录为「匿名」 |
| `ID` | 题目编号 | 四位十六进制，如 `A3F9` |
| `Star` | 重要程度 | `0`~`3` |
| `edition` | 版本 | `人教A版` |
| `volume` | 册别 | `上册` |
| `chapter` | 章别 | 如 `第一章 集合` |

### 5.2 JSON 文件格式（题目文件 / 分级文件统一）

```json
{
  "items": [
    {
      "T1": "高一", "T2": "数学", "T3": 1, "T4": 1, "T5": 0,
      "T6": ["集合"],
      "T7": 2,
      "Ma": "已知集合 A={1,2}，则 A 的子集个数为（  ）",
      "MaTp": 1,
      "o": ["A. 2", "B. 4", "C. 8", "D. 16"],
      "As": "B",
      "Ana": "含 n 个元素的集合子集数为 2ⁿ = 4。",
      "User": "zhangsan",
      "ID": "A3F9",
      "Star": 0,
      "edition": "人教A版",
      "volume": "上册",
      "chapter": "第一章 集合"
    }
  ]
}
```

**校验要点**：顶层必须是 `{"items":[...]}`；`ID` 省略时系统自动生成四位十六进制编号；缺失维度字段会被填缺省值，可能导致归档到「通用」目录，应尽量填写完整。

## 6. 备份与积分

| 项目 | 规则 |
|---|---|
| 主存储 | GitHub 仓库 `bank/` 分级目录（自动提交，commit 信息标注新增/重复 Star+1） |
| 备份 | WebDAV（坚果云），在「我的」页配置后一键备份/恢复 |
| 积分 | 完成一题 +10；共享旧题 +5（含手动共享） |
| AI 月度审题 | 后端每月审一次错题，明显与高考考纲完全不符的题剔除 |

## 7. 异常与合规

| 异常 | 原因 | 处置 |
|---|---|---|
| 401 鉴权失败 | API Key 失效/未授权 | 到「我的」页更新密钥或联系管理员重新下发密文 |
| 429 余额不足 | 付费模型欠费 | 切换免费模型（`glm-4-flash` / `glm-4v-flash`）或充值 |
| 图片解析错误 | 图片过小/损坏/格式不支持 | 换清晰原图，≥ 100×100 像素 |
| 共享失败 | 网络不通 / GitHub Token 失效 | 检查网络与 Token，重试 |
| 重复题 Star 已达 3 | 多次重复上传 | 停止重复上传，改为完善该题解析 |

**合规要求**：
- 仅上传有权共享的题目，遵守版权与隐私要求。
- 不得上传含个人身份信息、联系方式的内容。
- 隐私门：首次启动须同意《隐私声明》与《数据收集清单》后方可使用上传功能。

## 8. 操作速查卡

```
① 我的 → 设置用户数据（年级/教材）        [A 模式必做]
② 上传题目 → 选 A 或 B 模式
③ [B 模式] 选二级菜单：年级/科目/版本/册别/题型
④ 选图片（≤5MB，AI 识别）或 JSON 文件（≤5MB）
⑤ 确认自动共享开关（默认开）
⑥ 核对反馈：新题记编号 / 重复题看 Star+1 / 失败则排查
⑦ 我的 → WebDAV 一键备份（坚果云）
```

**分级路径**：`bank/年级/科目/版本/册别/题型.json`
**题型码**：1=选择 2=填空 3=简答 4=正误判断
**去重**：同题型文件内按题干（Ma）；重复 → Star+1（≤3）
**积分**：做题 +10 · 共享 +5
